# Zadanie 2

## O projekcie

Program symuluje lądowanie samochodem z silnikami rakietowymi, używając logiki rozmytej.
Użytkownik wystrzeliwuje samochód przez naciśnięcie, przeciągnięcie i puszczenie lewego przycisku myszki
tak jakby strzelał z procy. Następnie samochód próbuje bezpiecznie wylądować.


## Przygotowanie projektu

Potrzebny jest Python 3.10 lub nowszy.

1. Przejdź do folderu `zjazd2`:

   ```bash
   cd zjazd2
   ```

2. Utwórz środowisko wirtualne:

   ```bash
   python -m venv .venv
   ```

3. Aktywuj środowisko.

   Windows (PowerShell):

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Linux i macOS:

   ```bash
   source .venv/bin/activate
   ```

4. Zainstaluj zależności:

   ```bash
   pip install -r requirements.txt
   ```

## Uruchomienie

```bash
cd src
python main.py
```
